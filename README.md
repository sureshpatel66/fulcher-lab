# Fulcher Lab website

Independent static website for the Fulcher Lab at UCLA.

## Structure
- `index.html` — Home
- `research.html` — Research areas
- `people.html` — Lab members
- `publications.html` — Selected publications
- `news.html` — News and updates (add items by copying one `<li class="news-item">` block to the top)
- `contact.html` — Contact information
- `style.css` — Shared visual system
- `assets/` — Portraits and default avatar

## Maintenance
Keep team roles, research descriptions, and publication records aligned with UCLA-controlled sources and official publication records. The site is intentionally separate from any individual researcher's personal website.

To add Paola's photo: save `assets/paola-ruiz.jpg` and replace the avatar block on `people.html` using the snippet in the adjacent HTML comment.
